# Bot-yt-dlp

بوت تيليجرام لتنزيل الوسائط (فيديو / صور / صوت) من معظم المنصات، مبني على محرك تنزيل متعدد الطبقات مع خطط احتياطية تلقائية.

## المنصات المدعومة

YouTube · TikTok · Instagram · X (Twitter) · Facebook · Reddit · Pinterest · Vimeo · Twitch · SoundCloud · Threads · Bilibili · والمزيد

## محرك التنزيل متعدد الطبقات

كل رابط يمر عبر سلسلة استراتيجيات حتى ينجح واحد منها:

| الطبقة | الاستراتيجية | المنصات |
|---|---|---|
| 1 | fxtwitter API مباشر (صور + فيديو، بدون تسجيل دخول) | X / Twitter |
| 2 | yt-dlp بعملاء متعددين (لكل منصة سلسلة خاصة) | الكل |
| 3 | tikwm API (صور + موسيقى / فيديو HD) | TikTok |
| 4 | استخراج الصور/الكاروسيل عبر yt-dlp | الكل |
| 5 | gallery-dl كملاذ أخير للصور | الكل |

### يوتيوب
سلسلة عملاء لا تتطلب PO Token: `android_vr` → `web_embedded` → `tv_embedded` → `mweb/ios`، ومع الكوكيز يُجرّب عميل `web` أيضاً.

### المنشورات المصورة
- تُرسل الصور كألبومات (حتى 10 صور للمجموعة، وعدة مجموعات عند الحاجة)
- موسيقى السلايدشو تُرسل كملف صوتي منفصل
- زر **Make Video** يدمج الصور + الصوت في فيديو MP4 واحد

## التشغيل على Render (الخطة المجانية)

- خادم Flask وهمي (`/` و`/health`) لتلبية متطلب Web Service
- عاملان فقط (threads) + ترميز ffmpeg خفيف (`ultrafast`) لتفادي تجاوز 512MB رام
- كل الملفات المؤقتة في `/tmp` مع كنس دوري تلقائي

### متغيرات البيئة

| المتغير | إلزامي | الوصف |
|---|---|---|
| `BOT_TOKEN` | نعم | توكن بوت تيليجرام |
| `YTDLP_COOKIES` | لا | ملف كوكيز (Netscape أو base64) — **ضروري لإنستجرام** والمحتوى المقيد ويحسّن يوتيوب |
| `NUM_WORKERS` | لا | عدد عمال التنزيل (افتراضي 2، لا ترفعه على 512MB) |
| `MAX_SLIDESHOW_IMAGES` | لا | أقصى عدد صور للمنشور (افتراضي 20) |

> **ملاحظة عن إنستجرام:** إنستجرام يحظر عناوين IP السيرفرات السحابية بقوة. بدون كوكيز حساب حقيقي ستفشل أغلب روابطه مهما كانت الخطط الاحتياطية — هذا قيد المنصة نفسها وليس البوت.
